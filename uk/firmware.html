Atlas Control

Прошивка

Контролер працює під ArduPilot. Усі три моделі використовують спільний ідентифікатор плати, тому файли прошивки для них однакові.

Як прошити

Підключіть контролер до комп'ютера кабелем USB-C і відкрийте наземну станцію Mission Planner.

  1. Перейдіть у SETUP → Install Firmware.
  2. Оберіть Load custom firmware.
  3. Вкажіть завантажений файл .apj для вашого типу апарата.
  4. Дочекайтесь завершення запису і перепідключення плати.
Не використовуйте прошивки інших плат
Розворот сенсорів і склад периферії Atlas Control відрізняються від інших контролерів. Завантажуйте лише файли з цієї сторінки.

Відновлення через DFU

Якщо плата не визначається наземною станцією, її можна прошити напряму. Утримуйте кнопку boot під час підключення USB — контролер стартує в режимі DFU, після чого записується завантажувач за допомогою будь-якої утиліти DFU.

Логи

Логи польоту пишуться на карту microSD, встановлену на заводі. Зчитати їх можна через Mission Planner або вийнявши карту.
