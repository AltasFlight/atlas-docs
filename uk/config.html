Налаштування

PWM виходи

Контролер має 14 PWM-виходів. Усі підтримують звичайний PWM, канали 1–12 додатково підтримують DShot.

ГрупаВиходиТаймерПротоколи
Група 11, 2, 3, 4TIM5PWM, DShot
Група 25, 6, 7, 8TIM4PWM, DShot
Група 39, 10, 11, 12TIM1PWM, DShot
Група 413, 14TIM12лише PWM, без DMA
Важливо
Усі виходи однієї групи мають працювати на однаковій частоті та протоколі. Якщо хоч один канал групи використовує DShot, усі канали цієї групи теж мають бути на DShot.

GPIO

Будь-який з 14 виходів можна використати як GPIO — для реле, кнопок, вимірювання обертів тощо. Для цього задайте SERVOx_FUNCTION = -1.

Вхід RC

Контакт RC IN на серворейці підтримує всі односторонні протоколи ArduPilot: SBUS, CPPM, DSM. Той самий контакт є портом SERIAL5 (UART8) — саме він використовується для протоколів, яким потрібен UART.

Для CRSF, ELRS, FPort і SRXL2 задайте:

// FPort SERIAL5_PROTOCOL = 23 SERIAL5_OPTIONS = 15 // CRSF / ELRS SERIAL5_PROTOCOL = 23 SERIAL5_OPTIONS = 0 // SRXL2 — під'єднується лише пін TX приймача SERIAL5_PROTOCOL = 23 SERIAL5_OPTIONS = 4

Моніторинг батареї

DroneCAN — варіант за замовчуванням

Модуль живлення DroneCAN підключається до роз'єму POWER C або до CAN1.

BATT_MONITOR = 8 CAN_P1_DRIVER = 1

Аналоговий модуль

Аналоговий модуль підключається до роз'єму POWER A.

BATT_MONITOR = 4 BATT_VOLT_PIN = 16 BATT_CURR_PIN = 17 BATT_VOLT_MULT = 18.0 BATT_AMP_PERVLT = 24.0 BATT_VLT_OFFSET = -0.1
Другий монітор
Для другої батареї використовуйте набір параметрів BATT2_.

Компас

На платі є внутрішній компас RM3100. Контролер зазвичай розташований усередині апарата, де магнітне поле спотворене струмами силових кабелів, тому основним компасом краще призначити зовнішній — той, що в GPS-модулі. Зовнішні компаси підключаються до будь-якого з роз'ємів I2C.

Підігрів IMU

Контролер має вбудований підігрів інерціальних сенсорів: він утримує сталу температуру і тим зменшує дрейф. Цільова температура задається параметром BRD_HEAT_TARG, за замовчуванням 45 °C.
