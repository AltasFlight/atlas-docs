Atlas Control

Atlas Control — польотний контролер українського виробництва на базі процесора STM32H7 з сенсорами промислового класу. Повна сумісність з ArduPilot і PX4. Розроблений для академічних досліджень, комерційної інтеграції та оборонного застосування.

Налаштування

Налаштування FC

Базовий порядок UART

SERIAL0 = console = USB // MAVLink2 SERIAL1 = Telemetry1 = USART2 // MAVLink2 default, DMA SERIAL2 = Telemetry2 = USART6 // MAVLink2 default, DMA SERIAL3 = GPS1 = USART1 SERIAL4 = GPS2 = UART4 SERIAL6 = USER = UART7

Серійні протоколи можна налаштовувати відповідно до власних уподобань — порти адаптуються для різних периферійних пристроїв.

PWM виходи

Контролер підтримує до 14 PWM-виходів. Усі 14 каналів підтримують стандартний PWM. Канали 1–12 також підтримують DShot, канали 13–14 — тільки PWM (без DMA).

Групування виходів

ГрупаВиходиПротоколи
Група 11, 2, 3, 4PWM + DShot + Bi-directional DShot
Група 25, 6, 7, 8PWM + DShot
Група 39, 10, 11, 12PWM + DShot
Група 413, 14PWM only (без DMA)
⚠ Важливо
Всі виходи в межах однієї групи повинні використовувати однакову частоту та протокол. Якщо хоч один канал у групі використовує DShot — всі канали цієї групи також мають працювати на DShot.

GPIOs

Всі 14 виходів можна використовувати як GPIO (реле, кнопки, RPM тощо). Для цього встановіть SERVOx_FUNCTION = -1.

Нумерація GPIO (ArduPilot)

PWM1(M1)=50 PWM2(M2)=51 PWM3(M3)=52 PWM4(M4)=53 PWM5(M5)=54 PWM6(M6)=55 PWM7(M7)=56 PWM8(M8)=57 PWM9(M9)=58 PWM10(M10)=59 PWM11(M11)=60 PWM12(M12)=61 PWM13(M13)=62 PWM14(M14)=63

Аналогові входи

ADC Pin18 → ADC 6.6V Sense ADC Pin4 → ADC 3.3V Sense Analog 3.3V RSSI input pin = 6

Вхід RC

Пін RCIN підтримує всі RC-протоколи ArduPilot, окрім CRSF/ELRS та SRXL2 — вони потребують UART-з'єднання. Для CRSF та телеметрії FPort використовуйте SERIAL6 (UART7).

Налаштування SERIAL6 для RC

// FPort SERIAL6_PROTOCOL = 23 SERIAL6_OPTIONS = 15 // CRSF / ELRS SERIAL6_PROTOCOL = 23 SERIAL6_OPTIONS = 0 // SRXL2 (тільки TX пін приймача) SERIAL6_PROTOCOL = 23 SERIAL6_OPTIONS = 4

Моніторинг батареї

В комплекті постачається аналоговий PMU (до 14S). Підключіть до роз'єму Power A і встановіть параметри:

BATT_MONITOR = 4 BATT_CURR_PIN = 17 BATT_VOLT_PIN = 16 BATT_AMP_PERVLT = 24 BATT_VOLT_MULT = 18 BATT_VLT_OFFSET = -0.1
✓ DroneCAN PMU
Якщо використовуєте DroneCAN-модуль живлення — підключайте до роз'єму Power C. Для другого монітора використовуйте параметри BATT2.

Комплектація

Що в комплекті

Стандартна комплектація Atlas Control включає контролер та всі необхідні кабелі для підключення.

Контролер

1× Польотний контролер Atlas Control
  • У захисному алюмінієвому корпусі (98 × 62 × 16 мм)
  • З демпферами віброізоляції
  • З лакованою платою
  • З SD-карткою
1×Аналоговий модуль живлення PMU (до 14S)
