Atlas Control

Kit Contents

The base kit contains the controller, the power module and its cable. Additional options are discussed separately.

Base kit

  • Atlas Control board
  • Plastic enclosure
  • microSD card
  • CAN PMU lite power module, up to 60S
  • Power module cable

Optional (on request)

  • Conformal coating of the PCB
  • Aluminium enclosure
  • Cable set (contents below)

Cable set

2×JST-GH 1.25 mm, 6-pin (reversible)
1×JST-GH 1.25 mm, 3-pin
4×JST-GH 1.25 mm, 4-pin
2×JST-GH 1.25 mm, 6-pin
1×JST-GH 1.25 mm, 7-pin
1×JST-GH 1.25 mm, 10-pin
1×Servo cable
