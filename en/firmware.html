Atlas Control

Firmware

The controller runs ArduPilot. All three models share the same board identifier, so the firmware files are the same for any of them.

Loading firmware

Connect the controller to a computer with a USB-C cable and open the Mission Planner ground station.

  1. Go to SETUP → Install Firmware.
  2. Choose Load custom firmware.
  3. Select the downloaded .apj file for your vehicle type.
  4. Wait for the write to finish and the board to reconnect.
Do not use firmware built for other boards
Atlas Control differs from other controllers in sensor rotation and peripheral layout. Only use the files from this page.

DFU recovery

If the board is not detected by the ground station it can be flashed directly. Hold the boot button while plugging in USB — the controller starts in DFU mode, after which the bootloader can be written with any DFU utility.

Logs

Flight logs are written to the microSD card fitted at the factory. They can be read through Mission Planner or by removing the card.
